Project Title: Student Result Manager

You will build a simple web page where you can:
	Add a student's name and marks
	Store students in an array
	Represent each student using an object
	Calculate total and average using functions
	Determine Pass/Fail using conditionals
	Display students using the DOM
	Loop through students using forEach
	Search for a student
	Show class statistics
